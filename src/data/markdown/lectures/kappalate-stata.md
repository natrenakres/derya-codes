  Stata package to estimate the local average treatment effect (LATE) using Abadie's kappa approach and other weighting estimators (with [Tymon Słoczyński](https://people.brandeis.edu/~tslocz/index.html) and [Jeffrey M. Wooldridge](https://econ.msu.edu/about/directory/Wooldridge-Jeffrey)).

  To download from [SSC](https://www.stata.com/support/ssc-installation/), type ``` ssc install kappalate ``` in Stata.
